\section{Testy Jednostkowe}

\subsection{Struktura testów jednostkowych}

Testy jednostkowe realizują zasadę \textbf{F.I.R.S.T.}:
\begin{itemize}
    \item \textbf{Fast} - szybkie wykonanie ($<$ 100ms każdy)
    \item \textbf{Independent} - niezależne od siebie
    \item \textbf{Repeatable} - powtarzalne w każdym środowisku
    \item \textbf{Self-validating} - automatyczne sprawdzanie wyniku
    \item \textbf{Timely} - pisane przed/równolegle z kodem produkcyjnym
\end{itemize}

\subsection{Testy encji domenowych}

\subsubsection{Testowanie klasy RNG}

Encja RNG jest fundamentalną częścią systemu, reprezentującą generator liczb losowych jako czysty obiekt domenowy.

\textbf{Testowane funkcjonalności:}
\begin{enumerate}
    \item \texttt{test\_create\_rng\_with\_valid\_data}
    \begin{itemize}
        \item Tworzenie encji z wszystkimi poprawnymi danymi
        \item Weryfikacja przypisania wszystkich pól
        \item Sprawdzenie domyślnych wartości (is\_active=True)
    \end{itemize}
    
    \item \texttt{test\_rng\_empty\_name\_raises\_error}
    \begin{itemize}
        \item Walidacja pustego pola name
        \item Oczekiwany ValueError z komunikatem
        \item Test granic - pusta nazwa niedozwolona
    \end{itemize}
    
    \item \texttt{test\_rng\_empty\_code\_path\_raises\_error}
    \begin{itemize}
        \item Walidacja pustego pola code\_path
        \item Oczekiwany ValueError
        \item Krytyczna walidacja - bez ścieżki nie ma wykonania
    \end{itemize}
    
    \item \texttt{test\_rng\_validate\_for\_execution\_active}
    \begin{itemize}
        \item Metoda validate\_for\_execution() dla aktywnego RNG
        \item Zwraca True gdy is\_active=True i code\_path niepuste
    \end{itemize}
    
    \item \texttt{test\_rng\_validate\_for\_execution\_inactive}
    \begin{itemize}
        \item Test dla nieaktywnego RNG
        \item Zwraca False gdy is\_active=False
        \item Mechanizm wyłączania generatorów bez usuwania
    \end{itemize}
    
    \item \texttt{test\_rng\_get\_parameter\_existing}
    \begin{itemize}
        \item Pobieranie istniejących parametrów (seed, a, c, m)
        \item Bezpieczny dostęp przez metodę get\_parameter()
    \end{itemize}
    
    \item \texttt{test\_rng\_get\_parameter\_non\_existing\_with\_default}
    \begin{itemize}
        \item Próba pobrania nieistniejącego parametru
        \item Zwrócenie wartości domyślnej
        \item Unikanie KeyError
    \end{itemize}
    
    \item \texttt{test\_rng\_none\_parameters\_initialized\_to\_empty\_dict}
    \begin{itemize}
        \item Inicjalizacja None parameters na \{\}
        \item Automatyczna konwersja w \_\_post\_init\_\_
    \end{itemize}
\end{enumerate}

\textbf{Wyniki:} 8/8 testów zaliczonych, pokrycie: 95\%, czas: 0.12s

\subsubsection{Testowanie klasy TestResult}

Encja TestResult przechowuje wyniki wykonania testów statystycznych.

\textbf{Testowane funkcjonalności:}
\begin{enumerate}
    \item \texttt{test\_create\_test\_result\_with\_valid\_data}
    \begin{itemize}
        \item Tworzenie wyniku testu z poprawnymi danymi
        \item Weryfikacja wszystkich pól
    \end{itemize}
    
    \item \texttt{test\_test\_result\_score\_above\_one\_raises\_error}
    \begin{itemize}
        \item Walidacja score $>$ 1.0
        \item Oczekiwany ValueError
        \item Ochrona przed nieprawidłowymi wynikami
    \end{itemize}
    
    \item \texttt{test\_test\_result\_score\_below\_zero\_raises\_error}
    \begin{itemize}
        \item Walidacja score $<$ 0.0
        \item Score musi być w przedziale [0,1]
    \end{itemize}
    
    \item \texttt{test\_test\_result\_negative\_samples\_count\_raises\_error}
    \begin{itemize}
        \item Walidacja ujemnej liczby próbek
        \item samples\_count $\geq$ 0
    \end{itemize}
\end{enumerate}

\textbf{Wyniki:} 4/4 testy zaliczone, pokrycie: 90\%, czas: 0.08s

        \item Oczekiwany status: 405 Method Not Allowed lub 404
    \end{itemize}
    
    \item \texttt{test\_run\_test\_with\_missing\_data}
    \begin{itemize}
        \item Scenariusz: POST z pustym body
        \item Walidacja wymaganych pól
        \item Oczekiwany status: 400 Bad Request lub 404
        \item Wymagane pola: test\_name, samples\_count
    \end{itemize}
\end{enumerate}

\subsection{Logika wykonania testów}

\subsubsection{Sekwencja wykonania}

\begin{enumerate}
    \item \textbf{Walidacja formularza:}
    \begin{itemize}
        \item Sprawdzenie, czy wybrano oba generatory
        \item Weryfikacja wyboru scenariuszy
        \item Weryfikacja wyboru liczby testów
        \item Sprawdzenie dostępności API
    \end{itemize}
    
    \item \textbf{Inicjalizacja testów:}
    \begin{itemize}
        \item Wybór pierwszych N testów z puli NIST (gdzie N to wybrana liczba: 3, 6 lub 9)
        \item Obliczenie łącznej liczby testów: $N \times 2$ generatory
        \item Reset licznika postępu
        \item Czyszczenie poprzednich wyników
    \end{itemize}
    
    \item \textbf{Wykonanie testów dla Generator 1:}
    \begin{itemize}
        \item Sekwencyjne wykonanie każdego testu z wybranego scenariusza
        \item Pomiar czasu wykonania każdego testu
        \item Aktualizacja postępu po każdym teście
        \item Obsługa błędów (kontynuacja testów mimo niepowodzenia)
    \end{itemize}
    
    \item \textbf{Wykonanie testów dla Generator 2:}
    \begin{itemize}
        \item Analogiczny proces jak dla Generator 1
        \item Niezależne wykonanie testów
    \end{itemize}
    
    \item \textbf{Agregacja wyników:}
    \begin{itemize}
        \item Obliczenie liczby testów zdanych/oblanych
        \item Kalkulacja średniego wyniku (score)
        \item Zsumowanie całkowitego czasu wykonania
        \item Określenie zwycięzcy na podstawie wskaźnika zdawalności i średniego wyniku
    \end{itemize}
\end{enumerate}

\subsubsection{Kryteria wyboru zwycięzcy}

System automatycznie określa zwycięzcę według następujących kryteriów:

\begin{enumerate}
    \item \textbf{Główne kryterium:} Wskaźnik zdawalności testów (pass rate)
    \begin{itemize}
        \item Obliczany jako: $\frac{\text{liczba testów zdanych}}{\text{liczba wszystkich testów}} \times 100\%$
        \item Generator z wyższym wskaźnikiem wygrywa
    \end{itemize}
    
    \item \textbf{Kryterium rozstrzygające:} Średni wynik (average score)
    \begin{itemize}
        \item W przypadku równego wskaźnika zdawalności
        \item Obliczany jako: $\frac{\sum_{i=1}^{n} \text{score}_i}{n}$
        \item Generator z wyższym średnim wynikiem wygrywa
    \end{itemize}
    
    \item \textbf{Remis:}
    \begin{itemize}
        \item Gdy oba kryteria są równe
        \item Wyświetlane jako "remis - podobna wydajność"
    \end{itemize}
\end{enumerate}
